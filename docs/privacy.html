요약 (쉬운 설명)
발주매니아는 회원가입이 없고, 회사 서버도 없습니다. 대표님이 입력하신 발주·재고·매출·직원 데이터는 전부 대표님 휴대폰 안에만 저장됩니다. 회사는 그 데이터를 수집하지도, 볼 수도 없습니다. 예외는 두 가지뿐입니다: ① 사용자가 직접 AI 기능을 켜고 사진을 찍으면 그 사진이 Google AI 서버로 전송되어 분석됩니다. ② 앱 하단 광고(Google AdMob)가 광고 표시를 위해 기기 광고 식별자 등을 수집합니다.

해촌전자 주식회사(이하 "회사")는 모바일 애플리케이션 "발주매니아"(이하 "앱") 이용자의 개인정보를 소중히 여기며, 대한민국 「개인정보 보호법」, EU 일반 개인정보 보호법(GDPR), 미국 캘리포니아 소비자 개인정보 보호법(CCPA/CPRA) 등 적용 가능한 국내외 법령을 준수합니다. 본 방침은 앱이 어떤 정보를 어떻게 처리하는지 설명합니다.

1. 회사가 수집하는 개인정보: 원칙적으로 없음

본 앱은 다음과 같은 구조로 설계되었습니다.

항목내용
회원가입 / 로그인없음. 계정을 만들지 않으며 이름, 이메일, 전화번호를 요구하지 않습니다.
회사 운영 서버없음. 회사는 이용자 데이터를 전송받는 서버를 운영하지 않습니다.
이용자 입력 데이터
(가게 정보, 발주·재고·매출·거래처·직원·메뉴·문서 사진 등)		이용자 기기(휴대폰) 내부 저장소에만 저장됩니다. 회사는 이 데이터에 접근할 수 없고, 수집·열람·전송하지 않습니다.
직원 정보(이름, 급여 등)이용자가 직접 입력하는 경우에 한하며, 기기 내부에만 저장됩니다. 해당 정보의 적법한 처리(직원 동의 등)에 대한 책임은 이를 입력·관리하는 이용자(사업주)에게 있습니다.

2. 제3자 서비스가 처리하는 정보

앱은 아래 두 가지 제3자 서비스를 사용하며, 이들은 각자의 개인정보처리방침에 따라 정보를 처리합니다. 회사는 아래 서비스가 수집한 데이터를 제공받거나 보관하지 않습니다.

2-1. Google AdMob (광고)

구분내용
목적앱 하단 배너 광고 표시 (앱을 무료로 제공하기 위함)
처리 주체Google LLC
수집될 수 있는 정보광고 식별자(ADID), 기기 정보(모델, OS 버전), 대략적 위치(IP 기반), 광고 상호작용 기록
이용자 통제기기 설정 → Google → 광고 → "광고 개인 최적화 선택 해제" 또는 광고 ID 재설정/삭제 가능
관련 방침Google 개인정보처리방침 · AdMob 데이터 안내

2-2. Google Gemini API (AI 정밀인식 — 선택 기능)

구분내용
작동 조건기본적으로 꺼져 있음. 이용자가 직접 본인의 Google API 키를 발급받아 앱 설정에 입력한 경우에만 작동
전송되는 정보이용자가 촬영/선택한 문서 사진(영수증, 매출일보, 사업자등록증, 메뉴판 등)과 그 인식 텍스트가 Google 서버로 전송되어 분석 후 결과가 반환됨
API 키 보관이용자 기기 내부에만 저장. 회사로 전송되지 않음
유의사항사진에 개인정보(성명, 사업자번호, 카드번호 등)가 포함될 수 있으므로, 민감한 문서의 AI 분석 여부는 이용자가 스스로 판단해야 합니다. 국외(Google 서버 소재지) 전송이 발생할 수 있습니다.
관련 방침Google 개인정보처리방침 · Gemini API 이용약관

4. 보유 기간 및 파기

모든 이용자 데이터는 이용자 기기에만 존재하므로, 앱을 삭제하면 즉시 모든 데이터가 파기됩니다. 회사에는 파기할 데이터 자체가 존재하지 않습니다. 제3자 서비스(Google)가 보유한 정보의 보유 기간은 해당 서비스의 방침을 따릅니다.

5. 이용자의 권리 (GDPR·CCPA 포함)

회사는 이용자 개인정보를 보유하지 않으므로, 열람·정정·삭제·처리정지·이동권 등의 권리는 다음과 같이 행사할 수 있습니다.

  • 기기 내 데이터: 앱 내에서 직접 수정·삭제하거나 앱 삭제로 전부 삭제
  • 광고 데이터: 기기 광고 설정에서 최적화 해제/ID 재설정, 또는 Google에 직접 요청
  • 판매·공유 거부(CCPA): 회사는 개인정보를 판매(sell)하거나 공유(share)하지 않습니다
  • 차별 금지: 권리 행사를 이유로 불이익을 주지 않습니다

6. 아동의 개인정보

본 앱은 사업자(성인)를 대상으로 하며, 만 14세 미만 아동(GDPR 기준 16세 미만, COPPA 기준 13세 미만)을 대상으로 하지 않고, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 개인정보의 안전성 확보

이용자 데이터는 기기 내부의 앱 전용 저장 공간에 저장되며, 운영체제의 앱 샌드박스 보호를 받습니다. 다만 기기 분실·도난, 루팅, 악성 앱 설치 등 이용자 기기 환경에서 발생하는 위험은 이용자의 관리 영역이므로, 기기 잠금(비밀번호·생체인증) 사용을 권장합니다.

8. 국외 이전

회사는 개인정보를 국외로 이전하지 않습니다. 다만 이용자가 AI 기능을 사용하거나 광고가 표시되는 과정에서 Google LLC(미국 등 Google 서버 소재지)로 정보가 전송될 수 있으며, 이는 이용자와 Google 간의 관계에서 해당 서비스 약관·방침에 따라 처리됩니다.

9. 방침의 변경

본 방침이 변경되는 경우 앱 내 공지 또는 본 페이지 갱신을 통해 알립니다. 중요한 변경(수집 항목 추가 등)의 경우 시행 최소 7일 전(이용자에게 불리한 변경은 30일 전)에 고지합니다.
